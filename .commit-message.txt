fix(web): expose NEXT_PUBLIC_API_URL to next build via ARG

NEXT_PUBLIC_* values are inlined into the client bundle at build time, not
read from process.env at runtime. Railway exposes service vars during the
Docker build, but RUN steps only see them via explicit ARG.

Without these lines the bundled JS baked in the dev fallback
http://localhost:4000 and the production /status page sat stuck on
"Loading probes…" with a pending request to localhost.

Also documents the lesson in CLAUDE.md alongside the other Railway
gotchas.
