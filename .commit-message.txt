fix(web): hoist useMemo above early returns in /admin/vco

React error #310 ("Rendered fewer hooks than expected") on /admin/vco
when an ADMIN user signed in. The useMemo for filteredCustomers sat
*after* two `if (loading) return ...` and `if (!data) return ...`
branches. On first render `loading` is true, the early return fires
before useMemo is called. On the next render data is loaded, useMemo
runs, and React's hook count differs from the prior render — the page
crashes with the minified production error.

Hoist the useMemo above the conditional returns and let it operate on
`data?.customers ?? []` while data is still null.

The other operator pages (audits, customers/[id]) are fine — their
hooks are already above the early returns.
