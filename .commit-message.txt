feat: editable profile name + dashboard tile navigation

Three small but visible improvements to the customer self-care surface:

1. Dashboard tiles (My domains / Hosting / Support) were `<button disabled>`
   "Coming soon" stubs. They now navigate to /domains, /hosting, /tickets
   — destinations that already exist as PlaceholderPanel skeletons with
   honest roadmap status. Users get a real navigation experience instead
   of a dead button.

2. PATCH /v1/users/me on the API: any authenticated user can update their
   own fullName. Email/role intentionally not editable from this endpoint
   (verified flows + admin-only respectively). Returns the same UserPublic
   shape the auth endpoints emit.

3. Settings page Profile section becomes an editable form. Auth-context
   gets an `updateUser(next)` setter so the form patches the cached user
   in place after a successful save — no refetch round-trip.

The "Change password" / "2FA" / "Notification preferences" panels are still
PlaceholderPanels marked v1-wiring; those land with the auth-hardening chunk.
